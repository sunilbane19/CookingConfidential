# Cooking Confidential

A private, personal recipe and menu library.

## V1 direction

- Responsive web application: mobile for browsing, desktop for importing and editing.
- Recipes are the primary object.
- Menus can be created from scratch or copied and modified.
- Social sources (Instagram, Facebook, Reels, etc.) are recipe sources only: retain the source URL and extracted recipe content; do not store the source video/image.
- Recipes will support searchable metadata such as cuisine, country/region, course, ingredients, occasion, time and personal notes.
- Small-family sharing; no public social network or complex registration.
- Original imported files should be retained alongside structured recipe data.
- Backup/export is a design requirement.

The current repository contains the first visual/interaction prototype. Persistence, authentication, imports, recipe extraction and deployment will be added in subsequent milestones.
